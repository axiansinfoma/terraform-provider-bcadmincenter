# Data Source (bcadmincenter_scheduled_pte_operations)

Retrieves the per-tenant extension (PTE) installs and updates that are scheduled for a future deployment window on a Business Central environment.

Scheduled PTE versions survive an uninstall, so this data source is useful for auditing what will still be deployed to an environment.

~> **Note:** Requires Admin Center API version 2.29 or later.

## Example Usage

### Basic Example

```terraform
# Copyright (c) 2025 Axians Infoma GmbH
# SPDX-License-Identifier: MPL-2.0

# List every per-tenant extension install or update still scheduled for a future
# deployment window on an environment.
data "bcadmincenter_scheduled_pte_operations" "prod" {
  application_family = "BusinessCentral"
  environment_name   = "MyProdEnvironment"
}

output "scheduled_ptes" {
  value = [
    for op in data.bcadmincenter_scheduled_pte_operations.prod.operations :
    "${op.name} ${op.target_app_version} (${op.schedule_kind})"
  ]
}

# Narrow the result to a single extension by passing app_id.
data "bcadmincenter_scheduled_pte_operations" "my_pte" {
  application_family = "BusinessCentral"
  environment_name   = "MyProdEnvironment"
  app_id             = bcadmincenter_per_tenant_extension.my_pte.app_id
}

output "my_pte_pending_version" {
  value = try(data.bcadmincenter_scheduled_pte_operations.my_pte.operations[0].target_app_version, "none")
}
```

### Failing a Plan When Anything Is Still Queued

```terraform
data "bcadmincenter_scheduled_pte_operations" "prod" {
  application_family = "BusinessCentral"
  environment_name   = "MyProdEnvironment"
}

check "no_unexpected_pte_deployments" {
  assert {
    condition     = length(data.bcadmincenter_scheduled_pte_operations.prod.operations) == 0
    error_message = "Unexpected per-tenant extensions are still scheduled for deployment."
  }
}
```

## Schema

### Required

- `application_family` (String) The application family of the environment (e.g. `"BusinessCentral"`).
- `environment_name` (String) The name of the environment.

### Optional

- `aad_tenant_id` (String) The Azure AD tenant ID. If not specified, the provider's configured tenant ID is used.
- `app_id` (String) Optional filter. When set, only scheduled operations targeting this extension are returned.

### Read-Only

- `operations` (Attributes List) The scheduled per-tenant extension operations for the environment. (see [below for nested schema](#nestedatt--operations))

- `name` (String) Name of the extension, read from the uploaded `.app` package metadata.
- `publisher` (String) Publisher of the extension, read from the uploaded `.app` package metadata.
- `schedule_kind` (String) When the install will run (`"Immediate"`, `"UpdateWindow"`, `"NextMinorUpdate"`, or `"NextMajorUpdate"`).
- `source_app_version` (String) Source version. Empty for scheduled installs.
- `status` (String) Operation status. Always `"scheduled"` for this endpoint.
- `sync_mode` (String) Schema synchronisation mode supplied at upload time (`"Add"` or `"ForceSync"`).
- `target_app_version` (String) Version of the extension that will be installed.

- `type` (String) Operation type. Always `"Install"` for this endpoint.

## Notes

- Requires **Admin Center API version 2.29 or later**, which introduced the `apps/scheduledPteOperations` endpoint.
- Every entry has `status = "scheduled"`; the endpoint only returns operations awaiting a future deployment window.
- Scheduled versions are **not** removed when an extension is uninstalled. The [`bcadmincenter_per_tenant_extension`](../resources/per_tenant_extension.md) resource cancels the ones it created on destroy when `cancel_scheduled_on_destroy` is `true`.
- `name`, `publisher`, `sync_mode`, `language_id`, `country_code`, and `target_release` come from the snapshot of the original upload request and are `null` when the API omits the `parameters` block.
